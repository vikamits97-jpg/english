# Тренажёр английского

982 слова и фразы с примерами, 180 грамматических упражнений с проверкой, план на 26 недель.
Прогресс сохраняется в браузере: отметки «знаю / учить» по каждому слову и результаты по каждому упражнению.

## Как выложить в интернет за 10 минут

Нужен бесплатный аккаунт на github.com. Всё делается в браузере, ничего устанавливать не надо.

### 1. Создать репозиторий

1. Зайти на **github.com**, войти в аккаунт (или зарегистрироваться — кнопка *Sign up*).
2. Нажать **+** в правом верхнем углу → **New repository**.
3. **Repository name** — например `english`.
4. Выбрать **Public**. На бесплатном тарифе публикация сайта работает только для публичных репозиториев.
5. Нажать **Create repository**.

### 2. Загрузить файлы

1. На странице нового репозитория нажать ссылку **uploading an existing file**.
   (Если её не видно — вкладка **Add file** → **Upload files**.)
2. Перетащить в окно **все файлы из этой папки**: `index.html`, `sw.js`, `manifest.webmanifest`,
   `icon-192.png`, `icon-512.png`, `apple-touch-icon.png`.
   Важно: перетаскивать сами файлы, а не папку целиком — `index.html` должен лежать в корне.
3. Внизу нажать **Commit changes**.

### 3. Включить публикацию

1. Вкладка **Settings** (в самом репозитории, не в профиле).
2. Слева в меню — **Pages**.
3. **Source** → *Deploy from a branch*.
4. **Branch** → `main`, папка `/ (root)` → **Save**.
5. Подождать 1–2 минуты и обновить страницу. Наверху появится адрес вида
   **https://твой-логин.github.io/english/**

Этот адрес и есть готовый сайт. Он открывается на любом устройстве.

### 4. Поставить на экран айфона

1. Открыть адрес в **Safari** (именно в Safari, не в Chrome — иначе пункта не будет).
2. Кнопка **Поделиться** внизу → **На экран «Домой»** → **Добавить**.
3. Готово: иконка на рабочем столе, открывается без адресной строки, как приложение.

После первого открытия страница кэшируется и **работает без интернета**.

### 5. На компьютере

Просто открыть тот же адрес и добавить в закладки.

## Про прогресс

Прогресс хранится в браузере того устройства, где занимаешься. Между телефоном и компьютером
он сам не синхронизируется — это разные браузеры.

Чтобы перенести: вкладка **Прогресс** → **Скачать только прогресс** (файл `.json`),
затем на другом устройстве — **Загрузить прогресс из файла**.

## Обновление

Если понадобится заменить содержимое, загрузи новый `index.html` тем же способом
(**Add file** → **Upload files**), а в самом тренажёре перед этим скачай копию прогресса.
После обновления один раз обнови страницу дважды — старая версия лежит в офлайн-кэше.
